# 🛡️ Сервис детекции подозрительных транзакций с XAI и LLM-объяснением

## 📝 Описание проекта
Мы разрабатываем интеллектуальную систему для банка, которая в реальном времени определяет мошеннические транзакции. 
Наша фишка — не просто "черный ящик", а система, которая объясняет операционисту, *почему* транзакция заблокирована, используя связку **CatBoost** (для скорости) и **LLM** (для понятного языка).

**Тема курса:** Интеграция искусственного интеллекта в разработку.
**Команда:** 4 человека.

## 🎯 Бизнес-цель
Снизить финансовые потери банка от мошенничества и уменьшить время ручной проверки алертов для операционистов за счет автоматической генерации пояснений.

## 🛠 Технологический стек
*   **ML-ядро:** CatBoost (классический ML, табличные данные).
*   **XAI / LLM-слой:** YandexGPT API (или заглушка) для генерации текстовых объяснений.
*   **Сервис:** FastAPI, Docker.
*   **MLOps:** MLflow (трекинг экспериментов), Great Expectations (валидация данных), Evidently (мониторинг дрейфа).
*   **Тесты:** Pytest.

## 📊 Данные
Используем открытый датасет [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) с Kaggle. 
*Примечание: В реальном банке данные закрыты, но этот датасет идеально подходит по структуре (признаки PCA + сумма + время) для демонстрации архитектуры.*
