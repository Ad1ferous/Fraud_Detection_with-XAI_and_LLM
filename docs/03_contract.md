# Лекция 3. Проектирование ML-сервиса контракты и версионирование

## Контракт ML-сервиса

Антифрод-сервис банка (детекция подозрительных транзакций с ХАI и LLM)

Запрос

```http
POST /v1/score

transaction_id: "txn_839201"
user_id: "usr_10482"
amount: 15700.50
currency: "RUB"
merchant_id: "mrc_5521"
device_id: "dev_9f3a1c"
geo: {"country": "RU", "city": "Kazan"}
timestamp: "2026-09-14T11:32:00Z"
```

Клиент (платёжный шлюз) передаёт данные транзакции для оценки риска.

Сервис

Проверяет входные данные → получает предсказание модели + SHAP → генерирует LLM- объяснение → формирует ответ.

Успешный ответ

```json
{
  "risk_score": 0.87,
  "decision": "review",
  "explanation": "Крупная сумма в необычное время + новое устройство",
  "model_version": "2026-09-12"
}
```

Сервис возвращает оценку риска, решение и понятное объяснение, а также сообщает, какая версия модели сформировала ответ.
